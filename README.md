# House Price Prediction using Linear Regression

## Project Overview
This project predicts house prices using a Linear Regression model built with Scikit-Learn.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib

## Workflow
1. Data Cleaning
2. Handling Missing Values
3. Train-Test Split
4. Linear Regression Model Training
5. Model Evaluation

## Results
- R² Score: 0.374
- MAE: 30,829.94
- RMSE: 41,138.56
- MAPE: 18.74%
